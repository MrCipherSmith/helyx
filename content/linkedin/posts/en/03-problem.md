# EN · Problem → solution

**Tone:** direct, states a shared pain first. Good for a wider audience than
the technical variant.
**Suggested image:** `assets/en/02-features.png`.
**Length:** ~200 words.

---

Most AI coding tools have the same limitation: the session ends when you close
the window.

You lose the context. You lose what the agent was in the middle of. And if you
run more than one project, you spend a real part of your day explaining the
same decisions again.

Helyx solves this differently. The session does not live in the app — it lives
on your machine, in tmux, one per project, and it keeps working whether or not
anyone is watching. Telegram is only the window into it.

What that changes in practice:

• You start a long task, close the phone, and read the result an hour later.
• Each project has its own topic, so context never mixes between them.
• Decisions and constraints are stored and recalled by meaning, not by you
  remembering to repeat them.
• A code review request goes to several independent models at once, and you
  read every verdict instead of trusting one.
• Voice works in both directions, so the tool is usable while walking.

Everything runs on your own hardware. Your keys, your code, your machine.
