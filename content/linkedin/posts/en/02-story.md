I work on eleven projects. For a long time the hardest part was not the code.
It was that every time I came back to one of them, I had to rebuild in my head
what I had decided last week and why.

So I built Helyx.

Each project has its own topic in a Telegram forum, and behind each topic there
is a real Claude Code session running on my machine. I write or record a voice
message, the session picks it up, and I watch the work happen in a status
message that updates in place — the file it is reading, the tests it just ran,
the subagents it started. If it wants to run something I would rather it did
not, I deny it from the phone.

The part I did not expect to matter this much is memory. Decisions and
constraints go into a vector store, and the next session recalls them by
meaning. I stopped explaining the same architectural choice for the third time.

And it talks. I ask a question while walking, and it answers in text and speaks
a short summary back. The full answer stays in the chat for when I sit down.

It is open source and fully self-hosted. My keys, my machine, nothing leaves
the host.
