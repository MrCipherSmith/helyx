What makes it differentЧем он отличается

Not a chat wrapper. The session keeps running when you close the app. Это не обёртка над чатом. Сессия продолжает работать, когда ты закрываешь приложение.
01
Persistent sessionsСессии живут дальше
Every project gets a real Claude Code session in tmux. Close Telegram, come back in an hour — it is still where you left it. У каждого проекта настоящая сессия Claude Code в tmux. Закрой Telegram, вернись через час — всё там же, где оставил.
02
A topic per projectТопик на проект
Telegram forum topics map to projects one-to-one. Context never bleeds between them, and you switch by scrolling. Топики форума соответствуют проектам один к одному. Контекст не перетекает между ними, а переключение — это скролл.
03
Memory that outlives the sessionПамять переживает сессию
Decisions, constraints and gotchas go into pgvector and come back by meaning — so the next session already knows. Решения, ограничения и грабли уходят в pgvector и возвращаются по смыслу — следующая сессия уже в курсе.
04
Voice both waysГолос в обе стороны
Talk to it walking. It answers in text and speaks a short recap back — local TTS, no per-reply cost. Говори на ходу. Отвечает текстом и наговаривает короткий пересказ — локальный синтез, без оплаты за каждый ответ.
05
You see the work, liveРабота видна в реальном времени
A status message updates as the agent reads, edits and runs tests. Approve or deny tool calls from the phone. Статус обновляется, пока агент читает, правит и гоняет тесты. Разрешай или запрещай вызовы инструментов прямо с телефона.
06
Reviews from several modelsРевью от нескольких моделей
One request fans out to independent reviewers in parallel — Codex and other providers — and you read all verdicts. Один запрос расходится по независимым ревьюерам параллельно — Codex и другие провайдеры — и ты читаешь все вердикты.
