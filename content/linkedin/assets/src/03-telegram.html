An expired token is refreshed once, and only once — the retry is not wrapped in a loop. If the refresh itself fails, the request is rejected instead of retried, so a dead session cannot spin. Истёкший токен обновляется один раз и только один — повтор не завёрнут в цикл. Если само обновление падает, запрос отклоняется, а не повторяется, поэтому мёртвая сессия не может закрутиться.
