## Summary

Adapter abstraction layer for LLM provider registration and resolution. Provides a plugin-style registry pattern where different LLM adapters can be registered and retrieved by name, enabling multi-provider flexibility.

## Responsibility

Owns the adapter registry pattern for LLM provider abstraction. Defines the `ClaudeAdapter` interface contract, exposes `registerAdapter()` for runtime provider registration, and `getAdapter()` for lookup. Currently ships with the primary `claudeAdapter` that wraps the `claude/` module, but the architecture supports future providers (OpenAI, local models, etc.) without modifying adapter consumers.
