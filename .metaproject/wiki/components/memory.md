# Module memory

Version: 1.0.0
Type: component
Status: enriched

## Summary

Persistence and knowledge management subsystem — the data backbone of the bot. Provides PostgreSQL-based storage (via `postgres` tagged template literals), vector embeddings for semantic memory recall, short-term conversation history, long-term project knowledge extraction, and conversation summarization.

## Responsibility

Owns all data persistence and retrieval. Provides the `sql` tagged template literal (from the `postgres` library) used as the universal database connection across the entire codebase. Implements two-tier memory: short-term (recent conversation history scoped to session+chat with configurable window) and long-term (vector-based semantic memory stored as embeddings in PostgreSQL with recall by similarity search). Handles project knowledge extraction — automatically extracts and stores durable facts from completed conversation summaries. Provides conversation summarization with idle-timer triggering, overflow detection, and disconnect-time summarization. Manages embedding generation via Ollama or other configured providers.
