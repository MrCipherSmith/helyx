# Module dashboard

Version: 1.0.0

## Summary

A mobile-first Telegram Mini App for monitoring Claude Code sessions, viewing API stats and logs, managing memories, handling permissions, and exploring projects — all from a phone. Built with React + TypeScript + Vite, split into two webapps sharing an API client.

## Responsibility

Provides the rich Web UI layer for the Helyx system. Contains two independently-built web applications sharing a common API client: a full-featured dashboard (`dashboard/src/`) with pages for Overview, Sessions, SessionDetail, Logs, Memories, Permissions, Projects, Monitor, and Stats — and a lighter webapp (`dashboard/webapp/src/`) with Git browsing, message history, permission management, session monitoring, and PR management. Uses Telegram login for auth, i18n for localization, and hooks like `useEventStream` for real-time updates. Connected to the backend via `mcp/dashboard-api.ts`.
