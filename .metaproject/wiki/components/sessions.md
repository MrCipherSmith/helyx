# Module sessions

Version: 1.0.0

## Summary

Session lifecycle management — creation, routing, state machine, and cleanup of Claude Code CLI sessions. Provides the core session manager that tracks session state (connecting, connected, disconnected, terminating) and routes messages to the correct session.

## Responsibility

Owns the session lifecycle. The `SessionManager` (`manager.ts`) maintains in-memory session state, handles session creation with tmux integration, manages reconnection, and provides the `sessionManager` singleton used across the codebase. The router (`router.ts`) routes incoming messages to the appropriate session based on chat context and session mode (CLI vs standalone). The state machine (`state-machine.ts`) defines valid state transitions (connecting → connected → disconnected → terminating) and enforces lifecycle invariants. The session delete module (`delete.ts`) handles cascading cleanup of session resources including tmux sessions, DB records, and forum topic unbinding.
