## Summary

Background daemon scripts that run outside the main bot process: admin daemon (command execution, health monitoring), supervisor (process lifecycle), tmux session logger, and tmux watchdog (health checks and recovery).

## Responsibility

Owns all auxiliary process infrastructure. The admin-daemon picks up commands from the `admin_commands` DB table and executes them (project start/stop, bot restart, channel kill). The supervisor monitors Claude Code session health and triggers recovery actions on failure. The tmux-session-logger captures tmux session output for debugging. The tmux-watchdog periodically checks session health and restarts dead sessions. These scripts run as separate processes, communicating with the main bot through the database.
