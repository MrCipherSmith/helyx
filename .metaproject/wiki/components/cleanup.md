# Module cleanup

Version: 1.0.0
Type: component
Status: enriched

## Summary

Housekeeping subsystem that runs periodic maintenance jobs: message queue cleanup, log rotation, stale session archival, orphan CLI session cleanup, and memory TTL enforcement. Designed for cron or daemon-driven execution.

## Responsibility

Owns all routine data maintenance. Provides a registry of `CleanupJob` definitions (`ALL_JOBS`) that can be run individually or all at once via `runAllCleanupJobs()` or `runCleanup()`. Jobs cover: draining stale message queues, rotating logs, expiring archived messages past TTL, removing orphan CLI sessions, archiving stale sessions, and cleaning up old status messages. The runner orchestrates execution and collects results.
