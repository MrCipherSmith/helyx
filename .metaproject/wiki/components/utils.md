# Module utils

Version: 1.0.0

## Summary

Shared utility library providing API/transcription statistics recording, conversation curator (automated cleanup of stalled or low-value conversations), skill management (distillation, approval, handler registration, preprocessing), file helpers, HTML formatting, CLI config management, Claude usage tracking, TTS (text-to-speech via Kokoro), audio transcription, tmux monitoring, stream JSON parsing, and output monitoring.

## Responsibility

Owns all cross-cutting utilities that don't belong to a specific domain module. The skills subsystem handles the full lifecycle: preprocessing user input for skill trigger matching, distilling agent-created skills from conversations, managing user approval flows, and routing executed skills to handlers. The curator periodically reviews active conversations and suggests actions (pause, summarize, close) on stalled or degenerate loops. Stats utilities record API request metrics, transcription metrics, and error logs to the database for the monitoring dashboard. Also provides HTML sanitization, file I/O helpers, tmux session monitoring, and audio utilities (TTS synthesis and transcription).
