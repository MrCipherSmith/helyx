# Module channel

Version: 1.0.0

## Summary

The communication channel subsystem that bridges Telegram webhook updates into the bot's internal processing pipeline. Provides session affinity, recovery, status monitoring, permission validation, and tool routing for ephemeral Claude Code sessions.

## Responsibility

Owns the channel abstraction for Claude Code CLI session communication. Manages session-to-chat mapping with recovery from disconnects, polls session health and reconnects stale sessions, evaluates and routes skill/tool execution permissions, tracks session status transitions, and provides the Telegram message delivery bridge. The poller ensures sessions remain healthy by periodic checks and triggers reconnection when a session dies. The skill-evaluator gates tool execution through the permission system.
