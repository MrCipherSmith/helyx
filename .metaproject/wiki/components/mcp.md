## Summary

Model Context Protocol (MCP) server implementation that exposes bot functionality as tools consumable by Claude Code and other MCP clients. Acts as the API bridge between the bot's internal services and external AI agents.

## Responsibility

Owns the MCP server lifecycle and tool definitions. Implements the Model Context Protocol for bidirectional communication between the bot and Claude Code CLI. Provides tool definitions (`TOOL_DEFINITIONS`) for session management, project management, permission control, and knowledge operations. The MCP bridge routes tool execution requests to internal services. Includes a notification broadcaster for real-time events and a dashboard API bridge that exposes service-layer CRUD (sessions, projects, permissions, stats) as HTTP endpoints consumable by the dashboard webapp. Manages pending expectations for Claude Code tool responses.
